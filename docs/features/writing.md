# Shared screenplays and script story

Writing: OT sessions, ownership and sync, scenes, lists, the story map and history.

Read CLAUDE.md first: its rules (keys, ids, privacy, licences, focus, server load) apply here too.

- Shared screenplays (needs the Companion plugin, feature `scripts`): core `writing/TextOperation` (OT: apply/compose/transform/diff, cursor mapping; UTF-16 lengths like C#) and `writing/SharedScriptSession` (keeps the sent-but-unconfirmed change and the typed-since buffer, transforms both over others' edits, resends after a refusal, offline/restart-safe via `SharedScriptState`, reloads and keeps a copy if too far behind; single-threaded: run it on the UI scope). core-android `writing/SharedWriting` (`AppContainer.sharedWriting`) links a local script to a shared one per account (`WritingStore.saveLink`/`link`, `WritingDoc.sharedId`), so every shared script is also the user's own script and in their own backups; leaving, being removed or the owner stopping keeps it as theirs. Only the owner and invited people can open one. Editors route every text change through `session.edit`, apply `session.remote` with the selection moved by the op, mark `others`' cursors in the highlight; Share/Sharing (TV panel, phone dialog); TV documents list: each script's "Options" (or held OK) gives Delete (select twice) and Move and "Shared with you" in the documents list.
- Script ownership and sync: each script belongs to the account that made it (`WritingStore` owners; `docs` lists only the signed-in account's; scripts from before owners go to the first signed-in account; a backup never takes another account's script). With the Companion plugin, `SharedWriting.autoSync` (after sign-in, a few seconds after scripts are added/linked, every 5 minutes) puts this account's scripts on its server as private shared scripts (sharing = inviting members; "stop sharing" keeps it synced) and brings in the user's own scripts made elsewhere, but only when the account syncs: per-account device-only choice (`syncOptions`/`setSync`, default on only for the Primary server; a new server never gets scripts until switched on). One home server per script: `move(localId, account)` deletes the server copy and gives the script to another account (synced there when it's in use); `move(localId, null)` keeps it on this device only (`isDeviceOnly`). Unsynced scripts keep their history on the device (`WritingStore.localLog`/`historyStart`, core `story/LocalHistory`, compacted past 20,000 changes; not backed up), so `SharedWriting.history`/`authorship` always work. Labels: `WritingDoc.placeLabel`.
- Script story (lists, scenes, map, comments, history): core `writing/story`. Scenes are the script's headings, each carrying a hidden note `[[scene:id]]` (`Outline`: scenes, `addIds` once the writer leaves the line, `move`/`add` as text changes, `Hidden` maps editor offsets, `stripMarkers` for exports/word counts). `Story` records (list, entry, link, comment, scene details) merge field by field with who/when; Characters/Locations are detected from the script (`listItems`, stable `detectedId`). `StoryGraph` builds/filters/lays out the map (`EdgeKind` colours in `StoryColors`); `Attribution`/`History` give who-wrote-what, activity and restores. Shared scripts carry records in the same edit stream (`SharedScriptSession.changeStory`/`story`); unshared ones keep them in `WritingStore.readStory`/`saveStory` (and their backup). core-android `StoryContext`/`StoryHistory`/`ScriptStory`, `SharedWriting.storyFor`/`log`/`at`/`authorship`/`writers`/`history`. UI: phone editor tabs (`StoryPanels.kt`), TV editor buttons (`StoryTv.kt`; each comment has a Resolve/Reopen button beside it, held OK too; map is view + filter, links made from an entry).
