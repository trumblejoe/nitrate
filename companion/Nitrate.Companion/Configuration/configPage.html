Nitrate Companion

Updates

The plugin installs its own new versions from this server's plugin repositories every few hours, or at once with "Check for updates now" above (switch automatic updates off for it on its plugin page to stop the regular checks). Most updates change only the plugin's logic, which takes over at once with no restart (requests wait a moment, nothing playing stops). An update to the plugin itself only runs once the server restarts (Jellyfin shows "restart required"): off, you restart when it suits you; on, the server restarts itself in the two hours from the hour below when an update is waiting and nothing is playing.

Watching

Reads the text subtitles of films and episodes every night (Scheduled tasks → "Index spoken lines"), so people can find a line and jump to it. Subtitles inside video files are extracted once, so the first run over a big library takes a while.
Keeps every film and episode each person finishes, with the date, and their own rating and note. Only they can see it.
Nitrate shows a comic's first page at once and fetches the rest in one go. CBR, CB7 and CBT books are unpacked once into the server's cache folder (the most recently read within 4 GB are kept), so they open on every device.

Comic catalogs

Other comic servers everyone signed in here can browse and read in Nitrate: any OPDS catalog (Komga, Kavita, Calibre-web, CLU's feed…) or CLU with an API token (My Account → API Tokens). The server signs in for everyone, so these details never reach the apps, and it serves the books page by page (CBR too). Each person's place in a book is kept here, since the catalog sees one account for the whole household. Needs "Comics page by page".

Watch together and writing

Only the people who were in that viewing can read it again, and only when they open "Earlier chat".

Smart collections

Ordinary Jellyfin collections that keep themselves up to date from rules: every condition you fill in must hold, and in a list (genres, tags, studios, age ratings) any one will do. They're updated every night and ten minutes after titles are added or removed (Scheduled tasks → "Update smart collections"). Removing a rule leaves its collection as an ordinary one.

Private accounts

Private accounts never appear in the Nitrate apps' lists of people (watch partners, sharing a script) and can't be found by typing their name. Others can still send them a watch-partner request by exact user name; it always reads "sent", and they only learn the account exists if its owner accepts. People can also make themselves private in Nitrate.

Single sign-on (OpenID Connect)

Lets people sign in to the Nitrate apps with your identity provider. Only existing Jellyfin users can sign in: matched by user name, by a verified email that is their Jellyfin user name, or by a link below. Register this redirect address with the provider:
For example https://auth.example.com/application/o/jellyfin — its /.well-known/openid-configuration is read.
The address the provider sends people back to. Empty: the address the app used.
